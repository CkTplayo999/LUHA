# LUHA Fighting Game

An authentic 16-bit arcade stickman fighting game.

## Play Online
You can play directly in your browser via GitHub Pages:
**[Play LUHA Online](https://cktplayo999.github.io/LUHA/)**

## Controls
- **Player 1**: WASD to move, J/K/L/U/I/O or designated action keys.
- **Player 2**: Arrow keys to move, Numpad action keys.
